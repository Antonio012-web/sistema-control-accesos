# 🏫 Sistema de Control de Accesos

Sistema desarrollado como proyecto universitario, pensado para una escuela
de la comunidad, con el objetivo de registrar y controlar de forma organizada
las entradas y salidas de alumnos y docentes.

---

## 🎯 Objetivo del proyecto
- Mejorar la seguridad dentro de la institución educativa
- Llevar un registro claro y confiable de los accesos diarios
- Facilitar el control administrativo de alumnos y docentes

---

## 🚀 Funcionalidades
- Registro de entrada y salida
- Control de accesos por usuario
- Registro de fecha y hora
- Historial de movimientos
- Interfaz sencilla y clara para uso escolar

---

## 🛠 Tecnologías utilizadas
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

---

## 🔒 Nota
Este proyecto no cuenta con demo pública, ya que requiere configuración
de base de datos y entorno servidor.
